One pickup line for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty: a vending machine flirts with a passing human — it has exactly what they crave, it is always lit up at 2 a.m., and it never ghosts. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
